# Plan: Phase 7 Expenses, Returns, Reports

## Goal
Implement categorized expense recording, product and Pisai returns with financial/customer ledger offsets, pre-aggregated owner reporting KPIs, and unified chronological audit reports with date filtering and CSV export across `apps/api` and `apps/web`.

## Requirements
- `EXP-01`: Staff can log categorized shop expenses with server-assigned timestamps.
- `RET-01`: Returns can be processed against original bills or Pisai tokens with offsetting ledger entries.
- `REP-01`: Admin dashboard renders pre-aggregated cards for sales, grinding, expenses, and credit debt.
- `REP-02`: Admin can filter reports by date range and search customer credit histories with export options.

## Architecture & Implementation Details
1. **Prisma Schema (`apps/api/prisma/schema.prisma`)**:
   - `Expense` model:
     - `id`: UUID PK
     - `category`: `ELECTRICITY`, `LABOR`, `TEA_FOOD`, `MAINTENANCE`, `TRANSPORT`, `MISC`
     - `description`: String
     - `amount`: Float
     - `recordedById`: UUID FK to User
     - `createdAt`: DateTime (default now)
   - `BillReturn` model:
     - `id`: UUID PK
     - `returnNumber`: String (e.g. `RET-1001`)
     - `billId`: UUID FK (optional)
     - `pisaiId`: UUID FK (optional)
     - `customerId`: UUID FK (optional)
     - `amount`: Float
     - `reason`: String
     - `refundMethod`: `CASH`, `CREDIT_OFFSET`
     - `recordedById`: UUID FK to User
     - `createdAt`: DateTime (default now)

2. **Backend REST Routes (`apps/api/src/routes/`)**:
   - `expense.routes.ts`: `POST /api/expenses`, `GET /api/expenses` with category/date filters and activity logging (`EXP-01`).
   - `return.routes.ts`: `POST /api/returns` supporting cash refunds and credit offsets (automatically updating `Customer.currentBalance` and creating offsetting `LedgerEntry`), and `GET /api/returns` (`RET-01`).
   - `report.routes.ts`:
     - `GET /api/reports/dashboard-kpis`: Pre-aggregated metrics for Sales, Pisai, Expenses, Udhaar, and Drawer Cash (`REP-01`).
     - `GET /api/reports/ledger-stream`: Chronological feed merging all financial events with date range filters (`today`, `yesterday`, `7days`, `month`) and category pills (`REP-02`).
     - `GET /api/reports/export-csv`: CSV file generation (`REP-02`).

3. **Frontend UI Integration (`apps/web`)**:
   - `AdminDashboard.tsx`: Dynamically populates the 5 owner KPI summary cards from `/api/reports/dashboard-kpis`.
   - `ReportsView.tsx`: Displays unified financial activity stream, date filter toggle, category badges, expense recording modal, and browser CSV download.
