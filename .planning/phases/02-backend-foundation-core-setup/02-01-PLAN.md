# Plan 02-01: Express Monorepo Scaffolding & PostgreSQL Database Migrations

## Objective
Establish the backend service (`apps/api`) in the monorepo, configure Express with TypeScript, connect to PostgreSQL, and establish the core database migration pipeline with strict monetary and audit data types.

## Requirements Addressed
- **SETUP-01**: Express REST backend (`apps/api`) connected to PostgreSQL with monorepo orchestration.
- **SETUP-02**: Relational database schemas with migration tracking, transactional safety, and strict numeric data types for monetary values (`numeric(12, 2)`) and weights (`numeric(10, 3)`).

## Tasks
1. **Scaffold `apps/api` Service**:
   - Initialize package with `express`, `cors`, `helmet`, `dotenv`, `zod`, `morgan`, and TypeScript toolchain.
   - Configure monorepo orchestration in root `package.json` to run API and Web concurrently or independently.
2. **Database Migration Pipeline (PostgreSQL)**:
   - Configure PostgreSQL connection pool (`pg` / Prisma / Knex / SQL migration runner).
   - Set up migration runner and create initial base migration:
     - `roles`: `id`, `name`, `description`, `is_system`, `created_at`.
     - `permissions`: `id`, `code` (e.g. `can_discount`, `can_view_reports`), `description`, `category`.
     - `role_permissions`: `role_id`, `permission_id` composite primary key.
     - `users`: `id`, `username`, `password_hash`, `pin_hash`, `full_name`, `role_id`, `is_active`, `created_at`, `updated_at`.
     - `activity_log`: `id`, `user_id`, `action`, `entity_type`, `entity_id`, `details` (JSONB), `created_at`.
3. **Core Express Middleware & Health API**:
   - Centralized error-handling middleware with structured JSON responses.
   - Health check endpoint (`GET /api/health`) reporting DB connectivity, server uptime, and timestamp.
   - Request logger and correlation ID tracing.

## Verification
- Start PostgreSQL container or local service and run migration scripts.
- Run `curl http://localhost:5000/api/health` and verify `{"status":"ok","database":"connected"}`.
- Inspect database tables and confirm strict `numeric` types and relational foreign key constraints.
