# Phase 8 Plan 01: Daily Closing, Backup, Bill Void, Audit Log

## Goal
Implement end-of-day reconciliation with snapshot freezing (`CLOSE-01`), automated database backup on day-close (`BACKUP-01`), Admin bill and Pisai voiding with linked reversal ledger entries (`VOID-01`), and synchronous activity logging across all sensitive actions (`AUDIT-01`).

## Requirements Covered
- **CLOSE-01**: Admin shall perform an end-of-day closing action that computes a day-end snapshot (`daily_closing_records`) and locks the day against backdated edits.
- **BACKUP-01**: Confirming daily closing shall automatically trigger an automated PostgreSQL/SQLite database backup job.
- **VOID-01**: Admin shall have exclusive authority to void standard bills and Pisai tokens, creating linked reversal ledger entries without deleting original data.
- **AUDIT-01**: The backend shall synchronously record an immutable `activity_log` entry for all sensitive actions (price edits, discounts, voids, role changes, credit logs).

## Tasks
1. **Schema Update (`schema.prisma`)**:
   - Add `DailyClosingRecord` model.
   - Add void tracking fields (`voidReason`, `voidedById`, `voidedAt`) to `Bill` and `PisaiRecord`.
   - Run `prisma db push` and `prisma generate`.
2. **Database Backup Utility (`apps/api/src/utils/backup.ts`)**:
   - Create SQLite backup file with timestamp in `apps/api/backups/`.
   - Verify backup file exists and size > 0.
3. **Audit Logger Utility (`apps/api/src/utils/audit.ts`) & Route (`audit.routes.ts`)**:
   - Implement `recordActivityLog`.
   - Expose `GET /api/audit-logs` with filters.
4. **Daily Closing Route (`closing.routes.ts`)**:
   - `GET /api/closing/preview`: calculate real-time numbers for day.
   - `POST /api/closing`: execute day close, trigger backup, generate thermal Z-report receipt payload, freeze day, log audit.
   - `GET /api/closing/records`: historical list.
   - Day-lock enforcement to block backdated modifications.
5. **Void Endpoints**:
   - `POST /api/bills/:id/void`: `can_void_bills` permission check, day-lock check, credit reversal with `LedgerEntry`, audit log.
   - `POST /api/pisai/:id/void`: `can_void_bills` permission check, day-lock check, credit reversal, audit log.
6. **Frontend Integration**:
   - Wire `ZReportModal.tsx` to live `/api/closing/preview` and `/api/closing`.
   - Add Void action in `RecentInvoicesTable.tsx` / `ReportsView.tsx`.
   - Add Audit Log viewer in `ReportsView.tsx`.
7. **Verification**:
   - Run automated test suite `test-phase8.ts`.
   - Run TypeScript type checks (`tsc --noEmit`).
