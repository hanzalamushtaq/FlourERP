# Plan 01-01: Next.js Foundation, Design System & Typography

## Objective
Initialize the Next.js frontend application (`apps/web`), establish the mobile-first CSS design token architecture, integrate the Jameel Noori Nastaleeq Urdu web font, and build touch-optimized shared primitives (on-screen numeric keypad, touch cards, layout headers).

## Requirements Addressed
- **UI-01**: Mobile-first, touch-friendly UI framework with large high-contrast touch cards and responsive viewport scaling.
- **FONT-01**: Urdu typography rendering using Jameel Noori Nastaleeq for product cards and receipts.

## Tasks
1. **Scaffold Next.js App (`apps/web`)**: Initialize Next.js with React 19/18, TypeScript, and standard project layout.
2. **Design System & CSS Tokens**: Define a warm, high-contrast, premium color palette in `apps/web/app/globals.css` (primary wheat/amber, slate darks, emerald success, coral alerts) optimized for bright sunlit flour shop counters, with tactile button states, active feedback, and elevation tokens.
3. **Urdu Typography Integration**: Integrate Jameel Noori Nastaleeq web font (`@font-face`) and define font family utility classes (`font-nastaleeq`) ensuring proper ligatures, line heights, and baseline alignments.
4. **Shared UI Primitives**:
   - `NumericKeypad`: Large touch-target numpad (0-9, decimal `.`, Backspace, Clear, Quick increments like `+5`, `+10`, `+20`, `+40` KG).
   - `TouchCard`: Ergonomic high-contrast touch cards with icon, English title, prominent Nastaleeq title, and badge tags.
   - `HeaderNav`: Navigation bar supporting role toggle (Admin vs Biller preview mode), status badge, and quick PIN-lock trigger.

## Verification
- Run `npm run dev` in `apps/web` and verify browser rendering.
- Verify Urdu text "گندم کا آٹا (چکی)", "میدہ", "سوجی", "چوکر" renders with authentic Nastaleeq curves.
- Verify touch targets meet minimum 48px tactile size constraint.
