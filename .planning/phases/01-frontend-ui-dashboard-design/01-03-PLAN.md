# Plan 01-03: Admin Management Dashboard, Price Workflow & Reporting UI

## Objective
Build the Admin Management Dashboard interface, including pre-aggregated financial summary metric cards, the 24-hour Daily Price Confirmation modal (with both Admin-update and Biller-request simulation), customer credit profiles with live ledger balances, expense logging, returns workflow, and reporting views.

## Requirements Addressed
- **UI-03**: Comprehensive Admin Dashboard UI displaying pre-aggregated metric cards, daily price modal, customer ledger views, expense logging forms, and reports layout.

## Tasks
1. **Admin Metric Dashboard (`AdminDashboard`)**:
   - Pre-aggregated KPI summary cards:
     - Today's Total Sales (Product + Pisai)
     - Today's Pisai Grinding Total & Token Count
     - Today's Shop Expenses
     - Total Outstanding Customer Credit (Udhaar) Exposure
     - Net Daily Cash in Drawer
   - Quick action shortcuts: "Update Today's Prices", "Log Expense", "Issue Credit", "Daily Closing".
2. **Daily Price Confirmation Modal (`DailyPriceModal`)**:
   - Displays all products with current per-KG rates, last updated timestamps, and quick-edit inputs.
   - Dual simulation path:
     - **Admin Path**: Direct inline rate editing with "Confirm & Apply Today's Prices" or "Keep Yesterday's Rates".
     - **Biller Request Path**: Shows alert state "Prices pending confirmation from Admin. Bill on hold." with simulated approval/rejection banner.
3. **Customer Credit (Udhaar) & Profile View (`CustomerLedgerView`)**:
   - Customer search bar with existing accounts (Name, Phone, Outstanding Balance).
   - Customer profile drawer/card showing running balance, purchase history, and "Log Cash Repayment" modal.
4. **Expenses, Returns & Reports Layout (`ReportsView`)**:
   - Expense quick-entry dialog with category selector (Electricity, Labor, Maintenance, Tea/Refreshment).
   - Return processing modal linking back to bill number.
   - Filterable report tables with date range presets (Today, Yesterday, Last 7 Days, This Month) and mock CSV export.
5. **Interactive Navigation & View Switcher**:
   - Tabbed navigation switcher permitting effortless demonstration between Biller Counter, Grinding Tickets, Admin Dashboard, Customer Udhaar, and Daily Closing.

## Verification
- Verify all KPI cards calculate and display responsive metric charts.
- Trigger Daily Price Confirmation modal in both Admin and Biller preview states.
- Filter report tables across date presets and observe instant reactive UI updates.
