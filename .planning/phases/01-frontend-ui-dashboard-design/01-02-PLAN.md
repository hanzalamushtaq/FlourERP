# Plan 01-02: Biller Counter Billing & Grinding Ticket Experience

## Objective
Build the core touch-first Biller counter interface, featuring rapid product selection, instant weight↔amount calculation mode switching, explicit discount entry, dedicated Gundam Pisai grinding ticket screen with 4-digit token badge, printable thermal receipt previews, and the idle PIN-lock overlay.

## Requirements Addressed
- **UI-02**: Biller touch interface mockup including product selection cards, dual-mode weight↔amount input toggle, integrated on-screen numeric keypad, and a dedicated Pisai grinding ticket screen.
- **AUTH-02**: Idle-timeout PIN-lock overlay component that securely masks the screen without destroying session state.

## Tasks
1. **Product Billing Screen (`ProductBillingScreen`)**:
   - Product selection grid with large touch cards (Chakki Atta, Fine Atta, Maida, Suji, Chokar) showing rate per KG and Urdu script.
   - Dual-mode calculation toggle:
     - **Mode 1 (Weight → Amount)**: Biller inputs weight (e.g. `12.5` KG) → live calculated amount (`12.5 * 140 = Rs 1,750`).
     - **Mode 2 (Amount → Weight)**: Customer gives round money (e.g. `Rs 500`) → live calculated weight (`500 / 140 = 3.57` KG).
   - "Rate Not Set" visual guard state disabling selection and highlighting alert badge.
   - Discount drawer/input with explicit discount breakdown (`Subtotal`, `Discount`, `Net Total`).
   - Thermal receipt modal preview rendering simulated 58mm/80mm ESC/POS layout with receipt header, item lines, Urdu name, barcode/bill number, and footer.
2. **Gundam Pisai Grinding Ticket Screen (`PisaiBillingScreen`)**:
   - Dedicated service mode with weight entry in KG.
   - Service type selector: *Pisai* (Grinding only) vs *Safai + Pisai* (Cleaning + Grinding).
   - Direct manual charge input (since grinding rates vary by grain condition and agreement).
   - Customer name field (optional) and Udhaar toggle.
   - Live 4-digit sequential token card preview (e.g. `Token #0482`) formatted in extra-large font for customer handoff.
3. **Idle PIN-Lock Overlay (`PinLockOverlay`)**:
   - Simulated idle timer with quick lock button for instant testing.
   - Glassmorphism backdrop blur masking all sensitive billing numbers.
   - Responsive 4-digit circular PIN pad with tactile button feedback, masked dots indicator, and vibration/shake animation on incorrect attempt.

## Verification
- Toggle between Weight→Amount and Amount→Weight modes and confirm arithmetic updates live.
- Test quick weight buttons (`+5kg`, `+10kg`, `+20kg`, `+40kg` 1-bag).
- Trigger PIN-lock overlay, input 4-digit PIN, and verify smooth unlock without losing current bill draft.
