# Plan: Phase 6 Credit (Udhaar) & Ledger Module

## Goal
Implement customer credit tracking, customer profile ledger view, real-time cash repayments, and a unified append-only double-entry financial ledger (`ledger_entries`) across the FlourERP monorepo.

## Requirements
- `CRED-01`: Authorized users can issue credit bills to new or existing customers (`can_issue_credit`).
- `CRED-02`: Customer profile screen displays chronological bills, payments, and live derived balance.
- `CRED-03`: Cash repayments can be logged against outstanding balances in real time with thermal voucher generation.
- `LEDGER-01`: Every financial event (credit sale, cash repayment, balance adjustment) is recorded in the append-only `ledger_entries` table.

## Architecture & Implementation Details
1. **Prisma Schema (`apps/api/prisma/schema.prisma`)**:
   - `Customer` model: Extended with `currentBalance`, `address`, and relations to `LedgerEntry[]`.
   - `LedgerEntry` model:
     - `id`: UUID PK
     - `customerId`: UUID FK
     - `billId`: UUID FK (optional)
     - `pisaiId`: UUID FK (optional)
     - `type`: `DEBIT_PURCHASE`, `CREDIT_PAYMENT`, `ADJUSTMENT`
     - `amount`: Float
     - `description`: String
     - `balanceAfter`: Float (running balance snapshot)
     - `recordedById`: UUID FK to User
     - `receiptPayload`: ESC/POS formatted voucher payload (Text/Hex)
     - `createdAt`: DateTime (default now)

2. **Backend Billing & Pisai Integration**:
   - `POST /api/bills`: Transactional check for `can_issue_credit`. When `paymentMethod === 'CREDIT'`, updates `Customer.currentBalance` and inserts `LedgerEntry` (`DEBIT_PURCHASE`).
   - `POST /api/pisai`: Transactional check for `can_issue_credit`. When `paymentMethod === 'CREDIT'`, updates `Customer.currentBalance` and inserts `LedgerEntry` (`DEBIT_PURCHASE`).

3. **Customer & Ledger REST Routes (`apps/api/src/routes/customer.routes.ts`)**:
   - `GET /api/customers`: Searchable listing with current balance, transaction count, and last activity.
   - `GET /api/customers/:id`: Customer detail with all chronological ledger transactions.
   - `POST /api/customers`: Create customer profile with optional opening balance.
   - `POST /api/customers/:id/repayments`: Record cash repayment with atomic balance decrement, `CREDIT_PAYMENT` ledger entry, thermal voucher generation, and activity log.
   - `GET /api/customers/ledger/summary`: Aggregate receivables and active debtor count.

4. **Frontend UI (`apps/web/components/admin/CustomerLedgerView.tsx`)**:
   - Dynamic live customer list with search query debounce.
   - Customer profile timeline with chronological purchases (+Rs) and payments (-Rs).
   - Interactive Cash Repayment modal and New Customer modal wired to backend APIs.
