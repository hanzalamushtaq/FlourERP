# Plan: Phase 3 Product Catalog & Price Management

## Objective
Implement product catalog management, per-KG rates, `price_history` audit tracking, daily price confirmation protocol, and Biller price change request workflows.

## Requirements Covered
- `CAT-01`: Admin shall create, edit, activate/deactivate packaged flour products (standard unit: KG).
- `PRICE-01`: Admin shall set and update per-KG rates with automatic historical logging in `price_history`.
- `PRICE-02`: The system shall trigger a daily price confirmation on the first bill attempt of each calendar day, allowing Admin to update or confirm previous rates.
- `PRICE-03`: Counter Billers shall be blocked from directly updating prices; Biller price change requests shall hold the pending bill until Admin review or permit continuation with an Admin notification.

## Key Changes
1. Prisma Schema: `Product`, `PriceHistory`, `DailyPriceConfirmation`, `PriceChangeRequest` models.
2. REST API Routes:
   - `/api/products` (CRUD & rate modification with `price_history`)
   - `/api/prices/daily-status` (Check daily confirmation status)
   - `/api/prices/daily-confirm` (Admin bulk confirmation with `can_manage_prices` permission)
   - `/api/prices/request-change` (Biller price change submission)
   - `/api/prices/requests` & `/api/prices/requests/:id` (Admin review workflow)
3. Frontend UI:
   - `DailyPriceModal.tsx` connected to live daily status, admin confirmation, and biller price request endpoints.
