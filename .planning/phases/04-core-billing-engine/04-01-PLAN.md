# Plan: Phase 4 Core Billing Engine (Standard Products)

## Objective
Implement standard product billing logic with dual calculation modes, permission-gated discounts, sequential bill numbering with DB locks, and thermal receipt printing with identical reprint capability.

## Requirements Covered
- `BILL-01`: Touch-card product selection with dual calculation modes (Weight → Amount and Amount → Weight).
- `BILL-02`: Permission-gated discounts (`can_discount`) storing explicit discount amounts.
- `BILL-03`: Strictly sequential, non-resetting bill numbers using database-level locking during atomic bill transactions.
- `BILL-04`: Block bill generation and display a "Rate not set" warning if a product's current rate is null or zero.
- `PRINT-01`: Generate ESC/POS receipt payloads for thermal printers upon bill creation.
- `PRINT-02`: Provide an Admin/Biller reprint mechanism that re-renders the stored bill payload without altering sequence numbers or records.

## Key Changes
1. Prisma Schema: `Customer`, `BillSequence`, `Bill`, `BillItem` models.
2. REST API Routes:
   - `POST /api/bills` (Rate guard, discount RBAC guard, atomic sequence locking, ESC/POS generator)
   - `GET /api/bills` (Paginated list & search)
   - `GET /api/bills/:id/reprint` (Identical reprint retrieval)
   - `GET /api/customers/search` (Customer autocomplete)
3. Frontend UI:
   - `ProductBillingScreen.tsx` integrated with live product catalog, rate guard warning banner, discount permission lock, customer autocomplete, and real backend billing checkout.
